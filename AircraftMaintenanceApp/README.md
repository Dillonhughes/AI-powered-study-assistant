# Aircraft Maintenance App

This is a simple SwiftUI iOS application that lets you track multiple aircraft and predict when the next 100‑hour maintenance will be due.

## Features
- Add new aircraft with a name and current flight hours.
- Automatically calculates the next 100‑hour inspection based on the entered hours.
- Color-coded status indicates if an inspection is overdue, due soon, or not yet due.

## Building
Open **AircraftMaintenanceApp** as an Xcode project or create a new project and include these source files. The minimum deployment target is iOS 14 because the app uses SwiftUI.
